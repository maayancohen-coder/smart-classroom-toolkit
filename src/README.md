# Attendance Demo – I2SE Ex2

מערכת נוכחות לכיתה: המרצה לוחץ "פתח שיעור", הסטודנטים סורקים QR מתחלף, והמערכת מסמנת מי נוכח, מי חשוד (עם סיבה) ומי נעדר.

## הרצה (מחשב המרצה)

1. התקנה (פעם אחת): `pip install flask openpyxl`
2. הרצה, מתוך התיקייה: `python app.py`
3. בטרמינל יודפס קישור: `http://localhost:8000/lecturer?key=...`. פותחים אותו בדפדפן.
4. **HTTPS לטלפונים** (חובה, אחרת הדפדפן לא יתן מיקום): בטרמינל שני
   `cloudflared tunnel --url http://localhost:8000`
   ומקבלים כתובת `https://....trycloudflare.com`. פותחים את דף המרצה **דרך הכתובת הזאת** (באותו `?key=`), כדי שה-QR יכיל אותה.
5. לוחצים "השתמש במיקום שלי" ואז "פתח שיעור". מקרינים את המסך.

רשימת הסטודנטים: `data/students.csv` (עמודות `student_id,name`). מחליפים בקובץ של המרצה.

## מבנה

| קובץ | תפקיד |
|---|---|
| `attendance/tokens.py` | QR מתחלף חתום ב-HMAC |
| `attendance/checks.py` | הבדיקות: ממשק `AttendanceCheck` ומימוש לכל אות (Strategy) |
| `attendance/evaluator.py` | איחוד התוצאות לסטטוס |
| `attendance/service.py` | תרחישי השימוש |
| `attendance/repository.py` | רשימת סטודנטים, קשירת מכשיר, שיעורים |
| `app.py` + `templates/` | שכבת הווב |
| `tests/test_flow.py` | 18 תרחישים מקצה לקצה |

בדיקות: `python -m pytest -q tests`

## כללי ההחלטה

- בדיקה **חזקה** שנכשלה (מיקום רחוק או חסר, מיקום מזויף, קשירת מכשיר) ← חשוד.
- בדיקה **חלשה** (QR נסרק באיטיות, לא ברשת הקמפוס) ← חשוד רק אם שתיים נכשלו.
- סטודנט לא רואה את הסטטוס שלו, כדי שרמאי לא ילמד איזה אות תפס אותו.

## מגבלות ידועות

- QR בלבד לא עוצר וידאו חי של המסך. לכן יש מיקום, קשירת מכשיר וניתוח דפוסים.
- GPS בתוך מבנה לא מדויק, ולכן הגדר הוירטואלית היא בניין ולא חדר.
- מיקום אפשר לזייף. מזהים רק זיוף "גס" (דיוק מושלם, מיקום קפוא).
- המידע נשמר בזיכרון בלבד ונמחק בכיבוי השרת. הגיליון יוצא ל-Excel/CSV.
- `TRUST_PROXY_HEADERS=1` מניח שהשרת רץ מאחורי המנהרה. בלי מנהרה, כתובת ה-IP ניתנת לזיוף.
